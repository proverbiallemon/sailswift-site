every contested asset, every winner, every reason, in plain english. then one stamp fixes the order.

signed and notarized on macOS · keeps itself up to date · nothing is ever deleted

WHAT THE LEDGER DOES
1 reads every mod archive and maps which mods overwrite which CONFLICT
2 proposes a corrected load order with a plain reason for every move
3 warns about dead cargo: fully overridden mods, duplicates, unreadable files
4 click a warning, stamp a fix: keep one copy, set the rest ashore
5 nothing is written until stamped, and mod files are never deleted
⚓ return to the ship
